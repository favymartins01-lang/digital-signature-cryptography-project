# Digital Signature and Cryptography Project

## Project Overview
This project demonstrates practical applications of cryptography and information security through encryption, hashing, RSA cryptography, digital signatures, digital certificates, and TLS/HTTPS security.

## Project Objectives
- Understand symmetric encryption and decryption.
- Explore AES encryption using CyberChef.
- Perform SHA-256 hashing and examine hash integrity.
- Generate and examine HMAC values.
- Understand RSA public-key and private-key cryptography.
- Create and verify digital signatures.
- Investigate document tampering and signature verification.
- Explore digital certificates and TLS/HTTPS security.

## Tools and Technologies
- CyberChef
- CrypTool-Online
- OpenSSL
- Git and Git Bash
- Windows 11
- Web browser

## Project Structure
- `01_Cyberchef/` – Encryption exercise output.
- `02_RSA_Cryptography/` – RSA cryptography exercises.
- `03_Digital_Signatures/` – Digital signature exercises.
- `04_Digital_Certificates/` – Certificate exercises.
- `05_TLS_HTTPS/` – TLS and HTTPS exercises.
- `06_Screenshots/` – Practical evidence and screenshots.
- `07_Final_Report/` – Final project documentation.

## Practical Demonstrations
1. AES encryption and decryption.
2. Incorrect encryption key testing.
3. SHA-256 hash generation and modification testing.
4. HMAC generation and message modification testing.
5. RSA key generation and parameter examination.
6. Digital signature creation and verification.
7. Document tampering and verification testing.
8. Digital certificate examination.
9. TLS/HTTPS security examination.
